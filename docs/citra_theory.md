# 数学推导、假设和限制

## 核导数与 Hessian 上界

固定查询 q，令 `delta=q-z`，`k=exp(-||delta||²/(2 sigma²))`，sigma>0。
对文档坐标而非查询坐标求导：

```
grad_z k = k * (q-z) / sigma²                  [p]
Hess_z k = k * ((q-z)(q-z)^T/sigma⁴ - I/sigma²) [p,p]
```

令 `t=||q-z||²/sigma² >= 0`。正交方向特征值的绝对值是 `exp(-t/2)/sigma² <= 1/sigma²`；
径向特征值绝对值是 `|t-1| exp(-t/2)/sigma²`。t∈[0,1] 时不超过 1/sigma²，
t≥1 时在 t=3 取得最大值 `2 exp(-3/2)/sigma² < 1/sigma²`。
因此全球有效的谱范数上界是 `H=1/sigma²`，适用于从中心到任何文档的整个线段。
这比未经证明地仅在中心计算 Hessian 更可靠。当前未实现依赖查询距离和半径的紧界。

测试使用中心有限差分和独立 forward-mode Dual 自动微分对照解析梯度；不依赖 PyTorch。
同时在多种维度和 sigma 下显式计算 Hessian 的谱范数作数值检查；证明有效性来自上面的推导。

## 节点矩与一阶展开

每个节点 P 维护：数量、`c=mean(z)`、`r=max||z-c||`、
`V=sum v [m]`、`M=sum (z-c)v^T [p,m]`、`S=sum ||z-c||² ||v||₂`，
以及子节点、文档引用和版本/可用时间/有效区间/摄入时间元数据。

```
A_taylor(P) = k(q,c)V + M^T grad_z k(q,c)  [m]
```

泰勒余项满足 `|k(q,z)-k(q,c)-grad_z k(q,c)^T(z-c)| <= (H/2)||z-c||²`。
对带符号向量取三角不等式得到 `||A_exact(P)-A_taylor(P)||₂ <= H*S/2`。
S 必须逐文档取影响范数，不能先求和再取范数；相互抵消不意味着余项为零。
本实现仅对非叶节点做摘要近似；叶节点直接精确计算，可以增加扫描但保持语义正确。

## 多节点与自适应预算

查询 frontier 始终是根文档集合的无重叠完整分区。细化删除父节点，再加入它的两个子节点。
每个文档恰好属于一个 frontier 节点，因而总界为 `B_A=sum_P B_P`。
优先细化最大 B_P 的节点，直到 `L*B_A <= epsilon`。有限树最终到达全部精确的叶节点。
实现重新求和当前非负界，避免反复减去父界造成浮点消减。

更小 epsilon 使用相同细化序列的更长前缀，精确文档扫描数不会减少；epsilon=0 走 oracle。
不能保证每次细化后的实际误差单调，也不能保证延迟单调。不同 frontier 的理论界不必逐步下降；
本测试验证所选合成样本上的工作量/返回精度性质，不将这种观察当作一般性定理。

## 预测误差放大

当前验证头 `G(A)=reshape(W A)`，flatten 输出含所有通道和预测步。
`||G(A)-G(B)||₂ <= ||W||₂ ||A-B||₂ <= ||W||_F ||A-B||₂`。
FixedLinearForecaster 初始化时控制 Frobenius 范数并冻结数组；报告实际 `||W||_F` 作为 L。
F_TS 在同一输入和参数下相消。批量预测的形状是 `[B,C,H]`，单查询界约束一个样本；
多个样本联合 L2 界应组合为 `sqrt(sum_i bound_i²)`，不能只引用其中一个查询的界。
任何训练、文本编码或头参数变化都需要重新编码文档/更新统计量并重算 L；当前没有训练路径。
不能把无约束 Transformer 的常数设为 1。

## 时间与版本正确性

时间使用 timezone-aware datetime，内部统一 UTC。有效区间为 `[valid_from,valid_to)`。
快照首先筛选已可访问且 valid_from 已开始的版本，然后按 available_at、追加序号选最新版本，
最后检查 valid_to。最新版本过期不会复活旧版本；未来才开始生效的修订暂不取代旧版本。
修订允许追溯 valid_from，但不能在修订实际可用之前改变历史快照。
known ingested_at 增加系统可访问性约束；未知摄入时间保留 None，不伪造历史摄入时间。
verified 标记是导入方对 available_at 证据的声明，代码本身无法证明来源真实性。

第一版先过滤快照再建树，因此所有摘要内的文档都合法，没有在混合合法/非法节点上使用整节点摘要。
版本追加和插入使缓存失效；下次查询重建，旧快照对象保持不变。历史回填会改变系统当前对过去的认识，
可复现严格回测仍需固定导入 manifest 和实际摄入时间。这不是成熟的双时态数据库。

## 浮点适用范围

上述界是实数数学下的泰勒截断误差界。实现为 float64，使用 componentwise math.fsum 做 oracle
和最终分区求和。测试容差预先指定 `atol=1e-10, rtol=1e-10`，不按照观察到的误差修改理论界。
epsilon 的比较不加宽；epsilon=0 返回独立 oracle，同一路径下聚合结果逐位一致。
有限输入不代表所有中间运算都可表示，代码拒绝非有限摘要/界及主要溢出运算。
下溢、摘要累积和线性代数舍入误差不包含在理论余项中；当前没有区间算术或逐操作舍入认证。
因此本原型的 Certified 指解析截断误差证书及明确数值容差下的检查，不声称任意极端 IEEE 输入的
形式化机器数证书。epsilon 比数值精度更小时可出现容差内偏差；需形式化机器数保证的应用应回退精确
执行或增加可证明的舍入误差预算。任意外部提供的错误 L 都会破坏输出认证。

## 创新边界和反例

泰勒定理、RBF 导数、分层矩摘要、分支细化和线性 Lipschitz 界均为常见数学/算法构件，
不能作为论文原创性主张。可能的研究增量是：面向预测输出预算的历史版本合法证据求和算子，
以及同时维护时间过滤、影响矩和可验证输出误差的索引与优化算法；本版本尚未证明该增量。
全局 H 与三角不等式对大半径、强抵消影响可能非常松，使查询几乎遍历全集。
新 cutoff 重建树的开销可能大于 exact scan；模拟低半径簇的暖查询不代表真实系统更快。
文本可能无关甚至损害预测准确率。理论界不约束真实标签误差，也不证明新方法优于 ReTaMTSF。
